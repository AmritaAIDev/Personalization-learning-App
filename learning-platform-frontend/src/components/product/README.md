# Product UI primitives

These components are shared by the student-facing product surfaces that came
from the Figma/PDF plan.

- `PageHero` keeps page intros consistent without repeating header markup.
- `FeatureCard` is the reusable card shell for route explanations, mode cards,
  notebook summaries, tests, and doubt context panels.

The goal is to keep new screens compact, calm, and student-first while avoiding
static mock data as the product becomes fully backend-driven.
